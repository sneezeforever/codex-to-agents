# 更新说明

## 看板更新提醒

这次为 Agents 看板补上了更新提醒和更新入口。

升级后，打开看板每天最多自动检查一次更新，多个会话共享检查记录；有新版时在「插件更新」提示，是否安装由你决定。也可以随时手动检查。

隐藏看板时暂停状态查询，检查和安装之后的状态读取次数有限。更新过程保留已有配置和 SDD 文档；本地改动、分支分叉或任务正在执行时，会暂停安装并说明原因。

## 已安装用户：请先手动升级一次

之前通过 clone 安装的旧版没有检测代码，需要先按[升级教程](upgrading.md)手动更新并刷新本地安装。升级时沿用原来的安装参数，DSH 用户记得刷新插件后重启一下 DSH。
